# 闯关模式设计文档（MVP）

> 状态：MVP 已实现（分支 `feature/level-mode`）。
> 范围：只打磨玩法闭环，不做全部场景。实现取舍见文末「16. 实现状态」。

## 1. 设计支柱

1. **一关 30–60 秒**，随时可停、随时可重来。
2. **失败没有资源惩罚**，但要有情绪代价——由庄家承担。
3. **策略来自四个地方**：布阵、目标取舍、配额管理、对机器的熟悉。
4. **内容靠配方组合**，不靠手写关卡；只手写教学和 BOSS。

## 2. 核心循环

```
庄家宣布本关规则（指向演出）
  → 布阵（携带 2 个道具，按配额使用）
  → 拉杆发射
  → 落点 / 撞击判定
  → 目标进度更新
  → 成功 / 失败
  → 庄家反应 + 观众音效
  → 下一关
```

## 3. 关卡结构

- 场景 → 关卡 → 目标
- **MVP：1 个场景（橡木经典），6 关**，第 6 关为 BOSS。
- 每关 3 球，BOSS 4 球。

MVP 的关卡数刻意压到 6 关，目的是**在最短时间里跑完整条情绪弧线**：引导 → 施压 → 疯狂。
内容量不是 MVP 的目标，手感才是。

## 4. 目标系统

### 4.1 MVP 目标词汇

| 类型 | 字段 | 判定 |
|---|---|---|
| 必选洞 | `hole` | 球落入指定洞位 |
| 禁区洞 | `avoid` | 球落入禁区洞则本关失败 |
| 摧毁目标 | `destroy` | 目标耐久归零（球撞 2 次 / 锤子 1 次） |
| 球数限制 | `balls` | 全局，必选目标需在球数内完成 |
| 可选奖励 | `optional` | 完成给星，不影响通关 |

### 4.2 判定规则

- 每球落定后结算一次目标进度，`全部必选完成` 即通关，剩余球数不消耗。
- 落入禁区洞立即失败。
- 球数耗尽仍未完成 → 失败。

## 5. 关卡模板（MVP 2 个 + BOSS）

| 模板 | 配方 | 节奏 |
|---|---|---|
| 精准 `precision` | 2 个必选洞 + 1 个禁区洞，3 球 | 短、紧张 |
| 破坏 `destroy` | 2 个可破坏目标 + 1 个必选洞，3 球 | 中、道具主导 |
| 混合 `boss` | 1 必选洞 + 1 禁区 + 2 目标，4 球，庄家作弊（见 9.5） | 长、情绪高点 |

`路径`（穿点）与 `狂欢`（限时无限发射）留到 v1.1：前者需要新增"穿点"判定，后者需要改回球流程和计分模型，都不属于"打磨玩法"。

## 6. 随机面（关键约束）

每关拆成**规则**和**牌面**两层：

| 层 | 内容 | 认输时 |
|---|---|---|
| 规则 | 目标洞、球数、禁区、配额、限制 | **不变** |
| 牌面 | 障碍相位、可破坏目标位置、干扰钉位置、奖励点位置、发射随机偏移 | 重掷 |

规则不变是防刷：玩家不能靠认输换到一套更简单的目标。
但这也意味着**牌面必须有足够大的可变面**——如果一台机台本身是静态的（橡木经典没有障碍物），换种子等于没换。

因此 MVP 的每关至少要有 3 个可变面：

1. 干扰钉 / 奖励点的位置（3–4 个随机点）
2. 可破坏目标的位置与数量
3. 障碍物相位（有障碍物的机台）或发射随机偏移

## 7. 重开 / 认输

| 行为 | 种子 | 规则 | 关卡状态 | 星星 |
|---|---|---|---|---|
| 重开 | 不变 | 不变 | 从头再来 | 保留历史最好 |
| 认输 | 新种子 | 不变 | **不结束**，只是重新布置 | 不给星 |

- 认输的本质是「请庄家换一副牌」，不是失败。**关卡没有结束**，所以不存在扣星的问题。
- 换牌后：球数不重置，已完成的必选目标保留。
- 无次数限制。这是有意的取舍——认输是泄压阀，不是挑战手段。如果后续数据显示玩家在刷牌，再考虑加限制。
- 代价只有一个：庄家的态度随换牌次数递进——第一次客气，第二次不耐，第三次开始嘲讽。
- **前期（前 3 关）连败 3 次**，庄家主动提议换牌；中后期不再提议，但玩家仍可自己认输。

## 8. 道具（MVP 3 个）

**携带规则**：固定 2 个槽位，每关从 3 个道具里选 2 个带入。槽位扩展留到后续版本。

| 道具 | 效果 | MVP 参数 | 配额 |
|---|---|---|---|
| 磁场 `magnet` | 放在台面**任意位置**，吸引附近母球 | 半径 84、强度 1.0、整关有效 | 每关 2 次 |
| 挡板 `baffle` | 按住拖出**任意角度**的线段挡板 | 半宽 6.5、弹性 0.92、长 70–240 | 每关 1 次 |
| 锤子 `hammer` | 敲碎一颗钉子 / 一个可破坏目标 | 单点半径 34 | 每关 1 次 |

- 三种道具都在**发射前**使用，属于布阵阶段。
- 磁场不吸附钉子、挡板不是圆盘：台面有很多没有钉子的空档，工具必须能放进这些空档，否则「布阵」会被钉阵网格限制死。
- 道具选择走**背包面板**，不把全部道具铺在开场卡片上——道具数量会增长，铺开的 UI 迟早装不下。
- 锤子是"用配额换确定性"：破坏型关卡里可以跳过一次撞击。
- 升级树 MVP 只做 1 级（数值固定），后续再扩。

## 9. 庄家

**名字：庄家 · 七**。自称「本庄」，观众喊他「七爷」。

### 9.1 三幕弧线

| 阶段 | 关卡 | 表现 | 难度手段 |
|---|---|---|---|
| 引导 | 1–2 | 主动指目标、鼓励、放水 | 目标少、球多 |
| 施压 | 3–4 | 冷嘲、开始加修饰 | 加禁区、减球 |
| 疯狂 | 5–6 | 明着作弊、掀桌 | 作弊（见 9.5） |

### 9.2 表现手段（无立绘）

1. **筹码指针**：一枚发光筹码从屏幕边缘飞向目标点，落定脉动两下后淡出。这是他唯一的"身体"。
2. **聚光**：目标区域高亮，其余台面压暗 30%，复用现有 `suspense` 的压暗逻辑。
3. **声音身份**：固定低音音色 + 带混响 + 气泡抖动节奏。音色比立绘便宜，玩家会自己补全形象。

**顺序原则：先指，后说，再说结果。**
- 教学：筹码飞到 4 号洞 → 洞闪三下 → 气泡出字。
- 加害：筹码砸在台面上 → 震动 + 音效 → 障碍从落点长出。

加害必须**演成一个事件**，让玩家看到"他动手了"，而不是"台面莫名多了一块"。

### 9.3 播报优先级

同一时刻只允许一条播报，超时丢弃旧的：

```
教学 > 加害 > 嘲讽 > 鼓励
```

单条最长 1.2 秒，不阻塞操作。

### 9.4 事件表

| 事件 | 引导期 | 施压期 | 疯狂期 |
|---|---|---|---|
| 关卡开始 | 指目标 + 鼓励 | 冷嘲 | 威胁 |
| 落进必选洞 | 夸 | 敷衍 | 否认 |
| 差一点 | 安慰 | 嘲笑 | 大笑 |
| 摧毁目标 | — | 皱眉 | 抢话 |
| 失败 | 安慰 + 提议换牌 | 讥讽 | 狂笑 |
| 认输 | 调侃 | 讥讽 | 得意 |

### 9.5 庄家作弊（BOSS 关）

庄家有自己的一套「特权」，和玩家的道具系统**对称**：
玩家 3 件道具 + 配额，庄家 3 次作弊。这样读起来才是对等的 duel，而不是单方面被欺负。

**硬规则：每一条作弊都必须有可用的反制**，否则不是策略，是霸凌。

| 作弊 | 做法 | 反制 | 实现成本 |
|---|---|---|---|
| 挖洞 | 台面开一个陷阱洞，球经过被吞掉，记一次失败球 | 挡板架在洞前改球路 / 磁场把球吸开 | 低（新的感应圆形障碍） |
| 塞机关 | 塞入移动平台 / 小转盘 / 传送门，直接复用现有障碍物 | 算准相位绕开；可破坏的用锤子敲 | 极低（纯数据） |
| 收配额 | 拿走一次道具使用次数 | 无 | 极低 |
| 藏奖励点 | 遮掉可选奖励点 | 无（只影响星，不影响通关） | 低 |
| 倾斜机台 | 重力向量偏转 3–8° | 提前贴边，用挡板架回来 | 中（见下） |
| 伪造轮盘 | 改写转盘结果 | 无 | 仅狂赌深渊 |

**MVP 只做前四条。** 橡木经典本身没有机关，所以「塞机关」能形成"干净台面突然长出障碍"的强对比，性价比最高。

**倾斜机台**的物理成本几乎为零——`stepBallPhysics` 里 `b.vy += GRAVITY * dt` 改成向量 `b.vx += GX * dt; b.vy += GY * dt` 即可。难的是演出：物理世界倾斜了、墙体却没有倾斜，球会显得"往一边飘"而不是"台面歪了"。建议留到有美术资源、能给机柜加一点视觉倾斜时再做。

## 10. 观众

- **纯氛围音效**，不参与任何数值，不占 UI。
- 3 种：掌声、惊呼、倒吸凉气。
- 固定三拍：

```
0.0s  观众掌声 / 惊呼起
0.35s 庄家冷场台词
0.7s  掌声被压低（duck）→ 尴尬淡出
```

笑点来自"观众起哄 → 庄家泼冷水"的节奏，而不是台词本身。
观众音效**永不打断操作**。

## 11. 难度

MVP 不做实测命中率，用**手标难度**：

- 12 个洞人工标 1–5 分（越难落越贵）。
- 配方池 8–10 条，每条标注难度 1–5。
- 按关卡序号取难度区间抽配方，再用随机参数填洞位。

等有玩家数据后，再换成"模拟 500 次落球算命中率"的通用生成器。

## 12. 关卡数据格式

```json
{
  "id": "oak-03",
  "scene": "classic",
  "template": "precision",
  "difficulty": 3,
  "balls": 3,
  "objectives": [
    { "type": "hole", "slots": [3, 8], "mode": "all" },
    { "type": "avoid", "slots": [5] }
  ],
  "optional": [{ "type": "hole", "slots": [0] }],
  "loadoutSlots": 2,
  "quota": { "magnet": 2, "baffle": 1, "hammer": 1 },
  "randomSurface": ["interferencePegs", "bonusPoints", "launchJitter"]
}
```

- `objectives` / `optional` 是**规则**，认输不变。
- `randomSurface` 是**牌面**，由种子决定。

## 16. 实现状态（MVP）

已落地：

- 1 个场景（橡木经典）× 6 关，覆盖精准 / 破坏 / BOSS 三种模板。
- 目标词汇：必选洞、禁区洞、摧毁目标、可选奖励。球数限制由关卡数据直接给出。
- 牌面随机：干扰钉、可破坏目标、障碍相位。种子化，认输重掷、重开不变。
- 道具：磁场 / 挡板 / 锤子，携带 2 件，关内配额，发射前布阵并留在台面。
- 庄家：筹码指针、播报优先级、三段台词、三拍「观众欢呼 → 庄家泼冷水」。
- 观众：欢呼 / 惊呼 / 静场三种合成音效，无数值、无 UI。
- 星级与解锁：过关 1 星、奖励目标 +1、省下球 +1；上一关有星才解锁下一关。
- 重开（同种子）/ 认输（新种子，保留球数与进度）。

刻意未做（留到 v1.1）：

- 路径（穿点）、狂欢（限时无限发射）两个模板。
- 倾斜机台、伪造轮盘两条 BOSS 作弊。
- 落点热力图、道具升级树、多场景。
- 通用难度预算生成器——MVP 用 6 条手工配方代替，等有玩家数据再切。

实现时确定下来的两条细节：

- **目标判定在球落定后一次结算**，破坏目标中途被敲碎只更新 HUD，不提前结算。
  这样「踩禁区」永远优先于「目标已完成」，规则不会自相矛盾。
- **认输发生在关卡中途**，球数与已完成目标都保留，代价只有庄家的态度。
